
# Álgebra

Esta carpeta reúne subproyectos independientes. Este README funciona como índice; cada proyecto documenta su propio contenido y cómo ejecutarlo.

| Subproyecto | Enfoque | Documentación |
|---|---|---|
| `basic` | Ejercicio de programación sobre números felices. | [README de basic](basic/Readme.md) |
| `transformada` | Classroom interactivo de Octave para explorar transformaciones de números complejos. | [README de transformada](transformada/Readme.md) |

## Perspectiva de aprendizaje

### Propuestas

- Usar `basic` para introducir ciclos, estado y detección de repeticiones; después, abordar en `transformada` cómo una regla matemática modifica puntos y figuras.
- Mantener cada proyecto autónomo y usar este README para orientar la elección, no para repetir sus instrucciones.
- Añadir en futuros subproyectos una pregunta guía y una actividad que conecte el concepto con su implementación.

### Casos

- **Razonamiento algorítmico:** seguir una secuencia de valores, identificar cuándo termina y explicar qué ocurre si se repite un estado.
- **Exploración algebraica:** escoger puntos de entrada, aplicar una transformación y comparar el cambio numérico con el geométrico.
- **Actividad comparativa:** contrastar cómo un algoritmo discreto y una función sobre el plano representan y procesan información matemática.
